# Служебный проект

Отсюда **автоматически** публикуется зашифрованная версия приложения.
Без пароля она не открывается, а вместо кода в ней нечитаемый набор символов.

Исходного кода здесь нет. Рабочая версия хранится в закрытом проекте,
а публикацию выполняет `.github/workflows/publish.yml`:
сам каждые 30 минут (если приложение изменилось) или вручную — Actions → «Публикация приложения» → Run workflow.

**Вручную сюда ничего не загружайте.**
